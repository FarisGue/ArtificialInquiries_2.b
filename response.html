    Authentication information

    Omeka API Keys authenticate API requests using the permissions of the key owner. Local prototype provides anonymous access to public Omeka resources; switch to API Keys to create, edit or delete.

    GitHub, Google, and CAS identify external users independently and do not replace Omeka credentials.

    Authentication methods

    • Google OAuth: Functional
